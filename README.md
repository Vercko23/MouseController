# 🖐️ CV Virtual Mouse (Управление мышью с помощью веб-камеры)

Приложение на Python для управления курсором мыши и выполнения левого и правого кликов с помощью компьютерного зрения и распознавания жестов руки (MediaPipe + OpenCV + PyAutoGUI).

---

## 🎯 Жесты управления

| Жест | Действие | Описание |
|------|----------|----------|
| ☝️ **Указательный палец** | **Перемещение курсора** | Положение курсора на экране следует за кончиком указательного пальца (landmark 8). |
| 🤏 **Большой + Средний пальцы** | **Левый клик (ЛКМ)** | При касании кончиков большого и среднего пальцев выполняется одиночный клик левой кнопкой мыши. |
| 🤙 **Большой + Мизинец** | **Правый клик (ПКМ)** | При касании кончиков большого пальца и мизинца выполняется одиночный клик правой кнопкой мыши. |

---

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск приложения
```bash
python main.py
```

При первом запуске модель распознавания руки hand_landmarker.task автоматически загрузится в папку проекта.

---

## ⚙️ Параметры командной строки

Вы можете настраивать поведение приложения через флаги:

```bash
python main.py --help
```

- `--camera 0`: Индекс камеры (по умолчанию 0). Если у вас несколько камер, можно указать 1, 2 и т.д.
- `--smooth 0.25`: Коэффициент сглаживания курсора от 0.05 (максимально плавно, небольшая инерция) до 1.0 (без сглаживания). По умолчанию: 0.25.
- `--margin-x 0.15`, `--margin-y 0.15`: Размер активной области взаимодействия (отступы от краев кадра в долях). Позволяет комфортно доставать до всех 4-х углов экрана монитора.
- `--no-mouse`: Режим предпросмотра без реального перемещения системного курсора (удобно для калибровки и тестирования жестов).
- `--width 640`, `--height 480`: Разрешение захвата камеры.

Пример запуска с повышенной плавностью:
```bash
python main.py --smooth 0.18
```

Пример запуска в режиме тестирования (без влияния на курсор):
```bash
python main.py --no-mouse
```

## ⌨️ Управление
- Нажмите клавишу **q** или **ESC** в окне с видеопотоком камеры для корректного выхода из программы.

## 📁 Структура проекта
- `main.py` — Главный цикл приложения: захват видеопотока, координация модулей, отображение HUD и счетчиков кликов.
- `hand_tracker.py` — Модуль детекции кисти руки на базе MediaPipe Tasks, вычисление расстояний между пальцами и визуализация HUD.
- `mouse_controller.py` — Модуль преобразования координат, сглаживания движения курсора (EMA-фильтр) и независимой обработки ЛКМ / ПКМ.
- `requirements.txt` — Список зависимостей.
